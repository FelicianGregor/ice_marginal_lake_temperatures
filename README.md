# Lake surface water temperatures of ice-marginal lakes in Greenland: comparing different sensors/data sets
Comparison of lake surface (water) temperature data from Sentinel-3 LST L2, ASTER08 004, Landsat 4-9 and the CCI global lake dataset. 
Scripts mainly access and download data, preprocess it and then compare using simple statistics and visualization. This work has been done during a short-term internship (6 weeks) in the GEUS office Nuuk.

### Explanation of the different folders and scripts:
The most important script is `Sentinel_3_LST\data_analysis`. This uses all the preprocessed data stored in the other folders (named after their respective data source/sensor) and creates the figures for the short report and stores them in `plots` (not all of them, but most). 
The other folders and scripts are mainly for the purpose of documentation and organized in the following way (they are still quite messy, my apologies):
- `Sentinel_3_LST` contains all the scripts and data used to get the Sentinel-3 data: There is one script for downloading the data using the openeo API (`get_data_openeo_S3`), then one script for the data preparation (filtering etc.) called `S3_data_preparation`, and two less important scripts for selecting the largest lakes from Penny's GrIML based on the max numer of 1kmx1km pixels and a small script to explore potential reasons for the many extremely high values found for Sentinel-3 (appendix of the report). The folder `data` contains the downloaded raw `.nc` files, `data_2017_2025` as well but just for lake 6, and `data_processed` the prepared data ready for analysis.
- `Landsat4-9` only contains the surface temperature estimates from landsat in a `csv` file, calculated as described by How et al. 2025 (see `README` in this folder for more information). NOTE: Landsat estimates are only available for Lake Kangaarsuup Tasersua in Southwest Greenland (lake_id 6). 
- `Copernicus_cci_LSWT_dataset` contains the script for downloading CCI lake surface water temperatures and quality bands (`lakes_cci_data_download`, which works through an API provided by the CCI, using code from a github of the CCI lakes project, see script for details) and preprocessing (`data_preparation_CCI`). The script `check_lakes_Greenland` checks the location of the lakes that are contained in the CCI lake dataset and plots a map. All other files are auxiliary/data. NOTE: CCI estimates are only available for Lake Kangaarsuup Tasersua in Southwest Greenland (lake_id 6), but this could be extended to 6 more lakes that are ice-marginal in Greenland and in the CC global lake dataset.
- `ASTER08_LSWT` contains a script for data download using the earthaccess API (`ASTER08_data_download`) and data preparation/preprocessing (`data_preparation_ASTER08`). Since the cloud masking based on quality bands seemed to not work appropriately, a manual/visual cloud filtering has been used in the script `manually_class_cloud_scenes`, with the results written to `cloud_labels_finished.csv`.
- `plots` folder contains all graphs produced and used for the report, except for the overview maps produced using QGIS.
- `lake_polygons` stores all sorts of lake outlines etc. used during the analysis, as well as the GrIML dataset from Penny.

Due to the encounter of conflicts of different modules used, there are unfortunately two environments used during this project, and the dependencies are given in `environment-openeo2.yml` and `environment-griml.yml`. However, the griml environment is used for all scripts, and only the data download script for Sentinel-3 data uses the openeo environment, as noted also in the description of the script.
